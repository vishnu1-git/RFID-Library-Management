| SOP Layer | Layer Name | Core Implementation Components | Key Responsibilities |

| **Layer 1** | **Presentation Layer** | `frontend/src/App.tsx`<br>`frontend/src/pages/*`<br>`frontend/src/components/*` | Responsive staff portal, real-time telemetry dashboards, circulation counter, and RFID simulators using React 19, TypeScript, and Tailwind CSS. |
| **Layer 2** | **API & Security Layer** | `backend/app/api/v1/*`<br>`backend/app/core/security.py`<br>`backend/app/core/permissions.py` | FastAPI REST routers, Pydantic v2 validation, Argon2id password verification, signed Bearer JWT tokens, and RBAC security dependencies. |
| **Layer 3** | **Application Services** | `backend/app/services/*` | Domain business logic encapsulation (`CatalogService`, `CirculationService`, `GateService`, `InventoryService`, `MigrationService`, `FineService`). |
| **Layer 4** | **Integration & Middleware Layer** | `rfid-middleware/adapters/*`<br>`backend/app/integrations/ilms/*`<br>`backend/app/integrations/camera/*` | Hardware abstraction for Staff Desktop Pad, Mobile Handheld Wand, 3D Security Portal, and Smart Card readers. Strict protocol boundaries (NCIP 2.0 / SIP2) preventing legacy database corruption. |
| **Layer 5** | **Persistence Layer** | `backend/app/models/*`<br>`backend/app/db/session.py`<br>`database/schema.sql` | PostgreSQL 16 relational database with zero-friction development fallback to SQLite, versioned Alembic migrations, and immutable audit logs. |
| **Layer 6** | **Search & Catalog Indexing** | `backend/app/services/catalog_service.py`<br>`backend/app/db/base.py` | Indexed relational queries, ISBN lookup, and full-text keyword search across titles, authors, and classification categories. |

## 3. Core Architectural Constraints Traceability

| AISYS SOP Directive | Architectural Principle | Implementation Evidence |
| :--- | :--- | :--- |
| **Legacy ILMS Protection (Pages 1 & 3)** | System must never directly modify or corrupt the existing ILMS database. | All external ILMS interactions are isolated behind `app/integrations/ilms/base.py`, `ncip_adapter.py`, and `sip2_adapter.py`. LibraSync stores all operational data in its own database. |
| **Hardware Agnostic Middleware** | Replaceable RFID adapters without rewriting circulation services. | Abstract base class `RFIDReader` in `rfid-middleware/adapters/base.py` normalizes physical hardware reads into device-neutral `RFIDEvent` schemas. |
| **Staging-First Migration (Section 3)** | Safe spreadsheet ingestion with collision detection and rollback. | Staging table `migration_staging` buffers incoming raw rows. Duplicate detector checks intra-batch and active database. Rollback utility purges batch records atomically. |
| **Enterprise Cryptography** | Secure staff credential storage and tamper-proof sessions. | Argon2id (`t=2, m=64MB, p=2`) password hashing in `app/core/security.py` and cryptographically signed JWT tokens with expiration claims. |
